# Duma Boko Investigation Cases Summary

## Executive Summary

This research summary defines ten discovery-stage investigation cases for the Duma Boko Contradiction Engine v2. The pack contains sixty candidate source families and sixty flattened discovery seeds intended to guide later source resolution. The entries are investigation targets only, not verified evidence.

## Method And Evidentiary Guardrails

- No live web lookup was performed in this lane.
- Candidate titles are search descriptors, not verified source titles.
- Exact URLs are deliberately marked `UNSPECIFIED` where not verified.
- No quotes, timestamps, transcript lines, or contradictions are produced.
- Every candidate requires manual review before use as evidence.
